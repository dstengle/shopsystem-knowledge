# 0031 The agent renderer

2026-09-27. Slice 50's `agent` renderer publishes a role as `.claude/agents/<name>.md` under the directory asked for. `<name>` is the role's name without its kind, as the skill's directory and the diagram's file are named. Its heading block is the role's `harness` group as kb gives it, written through `kb.content`. Its body is the role's sections laid out as the markdown page lays out its sections, a heading and its body with the sections inside a level down, starting at level 1 since no title heading comes first. The one layout is shared by both renderers, not copied. An artifact with no `harness` group is published with an empty heading block and is not refused, as the skill renderer publishes a non-process with no steps. No harness limit on an agent is checked, since no scenario asks for one.
