# 0081 An agent migrates a markdown spec, against a check, from a brief

2026-10-10. A markdown spec is migrated into kb by an agent, not by a shop-knol command: given a brief kept in this repository (docs/migrating-a-spec-into-kb.md), the shop's types and the batch shape, it writes the batch itself, applies it to a scratch knowledge base and validates it until nothing is refused, then publishes from the scratch knowledge base over a copy of the repository and compares until only layout differs; the person approves that difference once, and the batch is applied on the day of switching over (0079), the markdown left unchanged meanwhile. Migration is done twice, for shopsystem-knowledge and shopsystem-kb, which does not warrant code. Supersedes 0070, 0077, 0078 and 0080; 0076 and 0079 stand. The user's decision.
