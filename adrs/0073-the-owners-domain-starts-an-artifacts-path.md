# 0073 An artifact's path names its owner's domain, product and context

2026-10-09. Below its type's IRI, an artifact's path is its owner's domain, its product, its bounded context and its name, e.g. `https://missingmass.io/shopsystem/capability/missingmass.io/ecommercesite/catalog/browse-the-catalog`, so the shop's types are named once, by their owner, and the content of any product they host is unique across organisations with no registry. The shop's types are shortened by fixed prefixes, in shop-knowledge alone. Refines 0072. The user's decision.
