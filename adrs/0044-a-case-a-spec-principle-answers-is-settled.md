# 0044 A case a spec principle answers is settled, not a question

2026-09-27. A case the spec does not name word for word, but which one of its stated principles answers for a reasonable user, is settled: it is formulated into a scenario and sliced, not logged as a QUESTION FOR THE SPEC and carried. A question for the spec is only a case no principle answers, or one two principles answer differently; each goes to the user once, and its answer is recorded as a decision and a spec sentence. Where a principle is missing, the spec gains the general sentence, not one per case. Extends 0039 from scenarios to questions. The skills that log such questions (formulating-features, slicing-into-increments) live in the shopsystem-bdd plugin (0002); until it carries this, the planner applies it.
