# 0061 A capability carries its place in the reading order

2026-10-08. A capability carries its place in its shop's reading order as a dotted number (3, 3.1, 3.1.2), sorted numerically, so one can be inserted without renumbering; the shop's `reading_order` goes, and a shop's capabilities are those linking to it. Each fact about membership is held once. The user's decision.
