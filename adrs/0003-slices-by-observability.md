# 0003 Slices are defined by what can be observed

2026-09-23. A slice is end to end, as thin as possible, and settles one unknown. Its kind is what it delivers: capability, verified by feature scenarios; enabling or stack, verified by a check command with a required result. Slices are ordered by implementation risk, walking skeleton first. Slicing writes only @slice tags into feature files. Assumption tags are not used; beliefs about use are tested by use. Once unknowns are spent, scenarios sharing a feature bundle into one slice.
