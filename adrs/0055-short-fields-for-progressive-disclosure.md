# 0055 Types give agents short fields to judge relevance

2026-10-07. Every type's glance fields are one short line or a link, and every part carries a short title, so an agent can judge relevance from a stub or a glance before reading a section, a part or the whole; long prose lives only in sections and part bodies. Length and single-line limits are written in the types, so kb checks them. The user's decision.
