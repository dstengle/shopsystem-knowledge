# 0070 Migrating a markdown spec into kb drafts batches; apply lands them

2026-10-09. A shop's existing markdown (`spec/`, `features/`, `adrs/`) is moved into kb by a `shop-knol` command that drafts `apply` batch files and lands nothing; the person or an agent fills what cannot be read mechanically, `shop-knol apply` lands them, and a publish with `render spec` compared with the original files confirms the move. The user's decision.
