# 0011 The planner writes no code

2026-09-27. Implementation plans carry no code: no scratch build, no code blocks generated from commits, no replay. A plan states each slice's scenarios or check, why they are red today, where the change lands by CLAUDE.md and which rule it implements once, the decisions the spec leaves open, reusable steps by name, and verification commands with counts derived from tags. Implementers write the code themselves under bdd-red-green and hand back on stop conditions. Reviewers run the suite and checks themselves; "cannot verify" fails a review. Architecture reviews run before planning, never as a task inside a plan. Supersedes the scratch-build practice used from 2026-09-23 to 2026-09-27.
