# 0001 BDD replaces TDD for shopsystem work

2026-09-22. Work in shopsystem repositories follows the shopsystem-bdd pipeline (formulating-features, slicing-into-increments, bdd-red-green) instead of superpowers TDD. Passing code must conform to approved Gherkin feature files, which are the functional contract. The one human gate is approval of feature files; everything else runs without a person in the loop and stops only on something unexpected.
