# 0041 How a markdown page lays out lists, tables and what sits inside them

2026-09-27. Fills in 0038. A field holding a list of plain values is its name, then one bullet a value nested one level in. A field of the page holding a list of mappings, a part collection among them, is taken out of the field list and laid out after it, before the sections: the field's name in bold on its own line, then a table with one column per key, in the order the keys first appear across the items, one row an item, an empty cell where an item lacks the key. Where a block cannot sit, in a table cell or a list of mappings inside a field group, a value is laid out inline: a plain value's lines joined by a space, a mapping as `key: value` pairs joined by `, `, a list's items joined by `; `, each laid out inline in turn.
