# 0039 A scenario the spec settles needs no approval

2026-09-27. Formulated scenarios that follow from an unambiguous passage of the spec are not held for the user's approval; slicing proceeds on them. Only a scenario that decides something the spec leaves open, or changes an approved scenario's meaning, waits for approval. The formulator's hand-back brief says which is which and cites the passage for each settled scenario. Narrows the gate in 0001. Carried by shopsystem-bdd 0.6.0 (2026-09-27): formulating-features marks each scenario settled or deciding, and the mark is only ever raised.
