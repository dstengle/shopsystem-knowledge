# 0076 The shop's types hold everything the markdown spec holds

2026-10-10. Before a markdown spec is migrated, the shop's types gain a place for everything it holds that they lack today: a capability's "Implementation, may change" and the shop's shared mechanisms, each as a new version of its type, published again by `render spec`, so that publishing a migrated shop reproduces its files and the comparison shows only real gaps. The user's decision.
