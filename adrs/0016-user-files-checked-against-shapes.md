# 0016 A user's file is checked against a shape, and a path the system refuses is a fault naming it

2026-09-27. `shape.violations` gives one fault per JSON Schema violation, `artifact` the file as named, `path` the parts joined with `/`, `rule` the keyword, `message` jsonschema's. The `content` shape is an object; the `batch` shape leaves `additionalProperties` open and checks `create`/`write` as strings and `content` as an object under a `oneOf` of two required-lists. A file that is not UTF-8 is a fault with rule `content` and message `it is not text that can be read: <Python's reason>`. `main` turns an `OSError` into a fault whose artifact is the path the error names (empty if it names none) and whose message is the operating system's reason. The printer joins a multi-line message into one line and prints the message alone when the fault has no artifact.
